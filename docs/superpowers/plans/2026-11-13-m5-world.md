# M5 shared-world integration plan

**Goal:** Expand the preserved M4 city with persistent physical housing first, then integrated guild/economic/PvP and world content within the execution budget.
**Authority:** pasted M5 request; AGENTS.md; ratified GDD v1.1. Autonomous native implementation, no design approval pause requested.
**Architecture:** Existing Godot/.NET/PostgreSQL. A versioned shared-world aggregate commits atomically with affected character aggregates. No housing instances; interiors use actual city coordinates and server collision/access checks. New modules split by housing, guild, market and PvP; touch menus issue bounded intents.
**Constraints:** Preserve M1–M4; Android/Windows/Web; no paid services/secrets; provisional configurable balance; one platform build batch unless a concrete failure requires a fix.

- [x] Persisted shared aggregate + character transaction; test stale-world and stale-character rollback, store reopen.
- [x] Physical housing intro/access/claim, furniture placement/rotation/removal, owner/visitor/guild permissions, storage/workshop/breeding/garden/rent, shared presentation; test duplicates and revoked access.
- [x] Persist guild membership/ranks/invitations/XP/quest/storage/buff and real shared hall, plus touch UI; test authority and membership persistence.
- [x] Escrow auction listing/search/buy/cancel/claim proceeds/fees with atomic inventory and concurrency guards; test full inventory/replay/restart.
- [x] Opt-in normalized arena combat with authoritative zones/rewards and abuse guards; record any team/war scope not completed.
- [x] Connected residential/market/industrial/PvE content, dungeon/boss mechanics, gated transport and bounded presentation streaming; preserve old scenes and combat values.
- [x] Focused server/client/network/DB proofs, one final review, honest status/operations/roadmap/asset docs, PR with APK/Windows/Web artifacts.

Review focus: offline seller earnings; stale aggregate conflict; storage item conservation; visitor revocation while inside; PvE stats leaking into PvP. Each is verified in its owning integration test. Anything unfinished is documented, never presented as a working menu.

Delivery boundary: four homes/one ground floor/two rooms/chairs, one guildhall, common normalized arena strike with ready teams, small connected industrial/open-ruins extension, housing-only geometry streaming. Full floors/furniture catalogue, guildhouse transfer/release/chat, territorial/scheduled wars, class-skill PvP balance, auction pagination/expiry, production art/mobile profiling and full world streaming remain open. Test/build evidence and artifact links are recorded in the PR; physical device/scaling qualification is not claimed.
